# LumenMetrics 需求与系统架构文档

## 1. 项目概述

LumenMetrics 是一款专为 SaaS 应用设计的全链路监控平台。它能够实时采集、存储并分析百万量级的系统日志与运行指标。其核心目标是解决传统管理系统在面对海量数据时的性能瓶颈，通过 Web Worker 多线程计算、IndexedDB 浏览器数据库、Canvas 高性能渲染等技术，实现极速的监控体验。

## 2. 核心功能需求

### 2.1 实时监控大盘 (Real-time Dashboard)

- **高频接入**：支持 WebSocket 每秒 100~500 条消息的持续流入。
- **动态图表**：实时刷新系统 CPU、内存、QPS 曲线，支持补间动画平滑过渡。
- **背压控制**：当数据流入速度超过渲染速度时，自动进行缓冲区降频处理。

### 2.2 海量日志探索器 (Million-level Log Explorer)

- **虚拟滚动 2.0**：支持动态高度的日志列表，处理 100 万条以上的检索结果。
- **多维过滤**：支持根据时间范围、错误级别（INFO/WARN/ERROR）、关键词进行毫秒级筛选。
- **审计追踪**：点击日志可查看该异常发生时的前后上下文（Contextual Logs）。

### 2.3 异常规则引擎 (Logic Engine)

- **自定义报警**：用户可通过 UI 配置监控规则（如：响应时间 > 500ms 持续 3 次）。
- **沙箱执行**：前端需要安全地解析配置的逻辑规则并对比实时流。

### 2.4 资产与权限中心 (RBAC & Audit)

- **细粒度权限**：支持页面级、按钮级、字段级（敏感日志脱敏）的权限控制。
- **操作审计**：记录管理员的所有配置变动历史。

## 3. 系统架构设计

项目采用 **“多线程分离 + 本地化存储”** 的现代前端架构：

### 3.1 五层架构模型

1. **通信层 (Transport Layer)**：基于 WebSocket 和 Axios，负责与后端或模拟 Server 进行全双工通信。
2. **调度层 (Orchestrator Layer - Web Worker)**：将主线程中笨重的排序、聚合统计、全文搜索逻辑移入独立的计算线程，确保 UI 响应性。
3. **持久化层 (Persistence Layer - IndexedDB)**：利用浏览器数据库存储百万条历史日志，解决内存溢出问题。
4. **状态层 (State Layer - Pinia)**：管理全局用户信息、实时指标快照及 UI 配置。
5. **表现层 (View Layer - Vue 3)**：采用 DOM (虚拟列表) + Canvas (高密点位图) 的混合渲染模式。

### 3.2 数据流向图

```
数据流入 (WS)` -> `缓冲区 (Buffer)` -> `Web Worker (清洗/分类)` -> `IndexedDB (存入)` -> `UI 组件 (按需读取)
```

## 4. 技术栈选型

| 维度         | 推荐技术                | 选型理由                                             |
| :----------- | :---------------------- | :--------------------------------------------------- |
| **核心框架** | Vue 3 (Composition API) | 极致的响应式性能与灵活的 Hook 逻辑抽离。             |
| **编程语言** | TypeScript 5.x          | 构建工业级应用必备，确保全链路类型安全。             |
| **构建工具** | Vite 6.x                | 极速的热更新性能与 Rollup 生态优化。                 |
| **本地存储** | **Dexie.js**            | IndexedDB 的高性能封装库，支持事务与索引查询。       |
| **计算引擎** | **Web Workers**         | 解决 JS 单线程计算 100w 数据时的卡顿问题。           |
| **可视化**   | ECharts 5 + Canvas      | ECharts 处理常规报表，原生 Canvas 处理超密集监控点。 |
| **UI 组件**  | Element Plus            | 快速构建标准的中后台界面。                           |
| **状态管理** | Pinia                   | 轻量级、模块化、完美支持 TS。                        |
