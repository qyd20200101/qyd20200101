## 2026/04/25 Day20学习日报


### 学习内容

#### 模拟面试复盘与底层攻克（第二轮）

##### Vue 3 响应式深度原理
- 理解了 `Proxy` 的惰性（Lazy）代理机制，相比 Vue 2 的 `defineProperty` 在处理 5 万条数据时具备极大的初始化优势。
- 明确了 `ref` 与 `reactive` 的本质区别：在处理“整个数组替换”的 API 场景下，必须使用 `ref` 以防止响应式丢失。
- 掌握了 `Object.freeze` 与 `shallowRef` 在海量静态数据场景下的架构取舍。

##### 复杂组件通信架构
- 纠正了递归组件事件传递的误区：Vue 事件不冒泡，掌握了通过 `Provide / Inject` 实现跨层级“扁平化”通信的架构方案。

##### 虚拟列表（Virtual List）算法精准化
- 闭卷默写了核心公式：`startIndex`、`visibleCount`、`endIndex` 以及关键的 `offsetY`（偏移量）计算。
- 探讨了动态高度列表下的“二分查找”缓存优化方案。

##### JS 内存与异步进阶
- 深入理解了 `WeakMap` 在深拷贝中的价值：不仅是解决循环引用，更是利用其弱引用特性防止拷贝后的内存泄漏。
- **Web Worker 多线程**：学习了如何通过 `Transferable Objects`（所有权转移）实现百万级数据的“零拷贝”传输。

##### 工程化与打包分析
- 实践了基于内容哈希（Hash）的分包策略，理解了 `manualChunks` 提高浏览器强缓存命中率的原理。
- 学习了 Gzip 压缩对高重复性数据（如 5w 条 JSON）的高达 90% 的压缩效率。

### 心得与收获
- **从“实现”到“严谨”的转变**：通过专项练习，我意识到之前对 `const` 和 `Proxy` 的理解存在碎片化。
- **UI 的“呼吸感”哲学**：在修复工具栏挤压问题时，深刻领悟到 `flex-shrink: 0` 对核心组件的保护作用。
- **全链路 Debug 意识**：今天在处理 `editor_zhang` 登录 401 问题时，通过后端日志精准定位。

- **问题 2**：工具栏 UI 在标签增多时发生形变。
- **问题 3**：TS 报错“元素隐式具有 any 类型”。
