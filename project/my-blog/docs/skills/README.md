# AI Skills 库

本目录存放了用于辅助个人技术博客开发的 AI Skill 定义。

## 如何使用
当你需要 AI 执行特定任务时，可以引用对应的 Skill 文件作为参考。例如：

1. **创作新文章**：
   > “请参考 `docs/skills/writing_skill.md` 的规范，帮我把这段笔记整理成博文。”

2. **整理标签**：
   > “根据文章内容，参考 `docs/skills/tagging_skill.md` 给出 3 个标签。”

3. **优化界面**：
   > “我想修改后台的删除确认框文案，请参考 `docs/skills/copy_optimization_skill.md` 给出建议。”
