         + 同步任务 -> 清空微任务 -> 浏览器渲染 -> 下一个宏任务

      + 树结构与递归组件

         + 大数据树渲染的虚拟化与懒加载优化思路
      + 发布订阅与组件通信
         + `EventEmitter`/事件总线与 `emit` 逐层传递的区别
         + 兄弟组件、跨层级通信适合用发布订阅

         + 手写 `deepClone`

+ 心得与收获： 总结学习成果，要详细说明对相关知识点的个人理解。
   + 今天通过模拟面试，我最大的收获是意识到“会写”和“会讲”是两回事。很多知识点平时在项目里能跑通，但要在面试中讲清楚底层原理、执行顺序和项目落地场景，必须把思路体系化。
   + 对虚拟列表和浏览器渲染的理解更深入了。以前只知道 `transform` 比 `top` 快，今天通过面试问答，真正把它和浏览器的渲染流水线（Layout / Paint / Composite）联系起来，明白了为什么 `translateY` 适合高频滚动场景。
   + 对闭包的理解从“函数访问变量”提升到了“作用域引用导致状态持久化”。尤其是在 Hook、定时器和 Token 刷新队列里的应用，让我认识到闭包既是能力也是风险，使用不当会造成内存泄漏。
   + 对 Promise 和异步控制流理解更立体了。尤其是 `then` 返回新 Promise 的意义，不只是为了链式调用，而是为了接住前一个回调的返回值、异常和 Promise 状态，这一点以前理解不够完整。
   + 对项目架构有了更强的表达能力。比如 RBAC 动态路由、数据管道式 computed 架构、发布订阅与 emit 区别、树结构递归算法等，不再只是“能实现”，而是开始有意识地从“为什么这样设计”来组织答案。
