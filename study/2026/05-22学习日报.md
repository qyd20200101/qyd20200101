## 2026/05/22 Day38 学习日报

+ 学习时长：约 8 小时

+ 学习内容：

  **1. vue-app 项目全链路走读**
  - 按"登录 → 路由守卫 → 数据加载 → 低代码 → 虚拟滚动 → F5 刷新 → KeepAlive"7 大环节逐一走读代码
  - 登录链路：Login.vue → userStore.login → loginApi → setToken → router.push 跳转
  - 路由守卫：beforeEach → 有 token/无 token 分支 → roles 为空时 getUserInfo 拉取 → generateAsyncRoutes 过滤 → addRoute 注册 → 重新匹配
  - Axios 封装：请求拦截器注入 Token → 响应拦截器脱壳返回 data → Token 无感刷新队列机制
  - 低代码：FormBuilder 拖拽 → FormComponent 数组存 JSON → FormConsumer 递归渲染 → SimpleASTGenerator 拼 .vue 字符串
  - 虚拟滚动：totalHeight 撑滚动条 → startIndex 动态切段 → visibleData 只渲染视口内数据
  - 数据管道：useAssetBusiness 纯数据加工（filter → sort → reduce）
  - F5 刷新恢复：token 从 localStorage 恢复 → roles 由守卫重新拉取 → 路由重组
  - KeepAlive + 标签页：tagsViewStore 管理 visitedViews + cachedViews 数组

  **2. react-app 技术迁移对比**
  - 路由守卫：Vue 用 beforeEach，React 用 AuthGuard 组件包裹
  - 状态管理：Vue 用 Pinia（defineStore + persist），React 用 zustand（create + persist 中间件）
  - Token 刷新：Vue 版有队列无感刷新，React 版 401 直接 window.location.href 强制跳转
  - KeepAlive：Vue 内置支持 + tagsViewStore，React 未实现
  - 低代码：Vue 有代码生成器 ASTGenerator，React 只有 designer + renderer

  **3. 建立 4 层思维模型**
  - ① 路由层（URL → 哪个组件 → 有没有权限）
  - ② 组件层（setup/onMounted 做了什么）
  - ③ 数据层（API → 拦截器 → 响应脱壳 → 响应式赋值）
  - ④ 渲染层（reactive 变了 → render → Diff → DOM 更新）

  **4. Promise 系统化学习**
  - 为什么需要：解决回调地狱，.then 扁平链
  - 三种状态：pending → fulfilled/rejected，不可逆
  - 链式调用核心：每次 .then() 返回新 Promise，return 普通值自动包装
  - 值穿透/错误穿透：不传回调则默认透传，catch 后可继续链
  - 6 个静态方法：all/race/allSettled/any/resolve/reject
  - async/await：async 始终返回 Promise，await = .then() 语法糖

  **5. 原型链系统化学习**
  - 三个核心属性：prototype（函数有）、__proto__（万物有）、constructor（原型 → 构造函数）
  - 原型链查找规则：找不到沿 __proto__ 往上直到 null
  - 关键节点：Function.__proto__ === Function.prototype、Object.prototype.__proto__ === null
  - instanceof 原理、new 运算符 4 步、hasOwnProperty

  **6. 深浅拷贝系统化**
  - 浅拷贝：展开/assign/slice，只复制第一层，嵌套仍引用
  - 深拷贝：JSON 方式的局限（丢函数/Date 变字符串/Symbol/循环引用报错）
  - 手写深拷贝：WeakMap 防循环 + Reflect.ownKeys 拿 Symbol + instanceof 处理 Date/RegExp
  - 特殊类型记忆：函 未 Sym Big 循 — 用 JSON 方式全丢

  **7. ESM vs CJS 系统化学习**
  - 四大核心区别：编译时/运行时、活引用/快照拷贝、this 指向、Tree-Shaking
  - 循环引用：ESM 安全、CJS 返回不完整对象

  **8. 知识点补充**
  - 模板字符串 4 个应用场景、深浅拷贝场景选择、事件冒泡 3 个阻止 API
  - 数组方法速查：不改原数组 9 个、改原数组 7 个、易踩坑点

  **9. 浏览器原理补充**
  - 浏览器内核、缓存机制（强缓存/协商缓存）
  - Event Loop（同步 → 微任务 → 可能渲染 → 宏任务）
  - 事件机制（捕获 → 目标 → 冒泡）+ 事件委托
  - XSS/CSRF/中间人攻击防御
  - 进程与线程、垃圾回收机制
  - 数组常用方法、手写题

+ 心得与收获：

  从"看得懂代码"推进到"能串联整页链路"。项目全链路的 5 大重难点全部走读完成。通过 4 层思维模型，任何一个新页面都能按这套方法快速理解。

  Promise、原型链、深浅拷贝、ESM/CJS 四个核心 JS 模块今天全部系统化梳理完毕，从"知道名词但说不全"变成"有完整知识地图"。最核心的收获是深浅拷贝的方式选择——JSON 方式的局限、手写版 WeakMap 防循环、特殊类型处理——现在可以流畅口述。

  Vue 和 React 两版项目对比后，对每个技术选型都有了清晰的理解：Vue 的 beforeEach 守卫 vs React 的 AuthGuard 组件、Pinia 的响应式 vs zustand 的不可变、Token 无感刷新 vs 硬跳转等。

  从 URL 输入到页面渲染的全链路越来越清晰——从 DNS 解析(CDN)、缓存请求、页面解析、脚本加载顺序到回流/重绘/合成层动画渲染，涉及计算机网络、服务器、HTML、CSS、JS 执行渲染多个层面，对整个流程的理解更加顺畅。
