## 2026/05/12 全天深度复盘日报

+ 学习时长：约 5 小时（跨 5 个计划日）

+ 学习内容（19 个知识块）：

  **Router 路由**
  - hash vs history 模式区别，路由匹配优先级（404 最后）
  - next({ path }) vs next(string)：效果相同，path 和 params 互斥
  - replace: true：替换历史记录不追加，F5 刷新防重复
  - { ...to, replace: true }：addRoute 后重新匹配不留重复历史
  - 导航全流程 9 步：Leave → Each → Update → Enter → RouteEnter → Resolve → After

  **生命周期**
  - 父子创建：父 setup → 父 beforeMount → 子 setup → 子 beforeMount → 子 mounted → 父 mounted
  - KeepAlive：首次 mounted → onActivated；再次只 onActivated；离开只 onDeactivated
  - 指令 7 钩子：created → beforeMount → mounted → beforeUpdate → updated → beforeUnmount → unmounted
  - 指令钩子嵌在组件生命周期之间（beforeMount→mounted / beforeUpdate→updated / beforeUnmount→unmounted）

  **原型链 + instanceof**
  - 三条必背链路：fn → Function.prototype → Object.prototype；obj → Foo.prototype → Object.prototype；Function/Obj 自指
  - 手写 instanceof：while 循环沿 __proto__ 往上找 constructor.prototype

  **异步组件**
  - defineAsyncComponent：loading/error/timeout/delay/onError 状态机
  - Suspense（实验性）：整棵树 fallback vs 单组件 loading
  - Teleport：DOM 搬家到 to，逻辑层级不变（props/事件/inject 全通）

  **Pinia 源码**
  - defineStore 单例：_s Map 懒注册，首次 useStore 才创建
  - 真实三层：activePinia inject + reactive $patch + 插件管道 pinia.use()

  **事件循环**
  - 宏任务(script/setTimeout) → 清空微任务(Promise.then) → 下一宏任务
  - new Promise executor 是同步的；await 后面是微任务
  - 混排题能排出 1→6→4→2→3→5 和 a→c→e→d→b

  **闭包 + 防抖**
  - 闭包核心：return 出去的内部函数仍持有原始作用域引用（不是"内部读外部"）
  - 防抖标准版←→立即执行版：冷却期 timer 判断

  **编译四阶段**
  - parse → transform(静态提升/patchFlag/事件缓存) → generate → render 执行
  - 编译期和运行时严格区分

  **Node.js 后端**
  - Express 洋葱模型：app.use 双向（next 进 → res.send 出）
  - JWT 双 token：accessToken 短(15min)频繁传 + refreshToken 长(7day)只传一次
  - SQLite：prepare + ? 占位符防注入

  **provide/inject**
  - 跨层级穿透，要响应式必须传 ref/reactive

  **算法**
  - 二叉树：前序根左右 / 中序左根右 / 后序左右根；层序 BFS 队列
  - LRU Cache：Map 版，迭代顺序 = 插入顺序，淘汰第一个
  - 链表反转：prev/cur/next 三指针
  - 环检测：快慢指针

  **HTTP 缓存**
  - 强缓存不发请求(200 from cache)；协商缓存发请求(304)
  - Cache-Control: no-cache 每次问服务器 / no-store 完全不存
  - F5 跳过强缓存走协商；Ctrl+F5 全部跳过全量下载

  **CORS 跨域**
  - 简单请求(GET/POST/表单)直接发；复杂请求先 OPTIONS 预检
  - 带 cookie 跨域不允许 Allow-Origin: *
  - 六种方案：CORS/proxy/Nginx/JSONP/WebSocket/postMessage
