## 2026/05/13 学习日报

+ 学习时长：约 3 小时

+ 学习内容（8 个知识块）：

  **低代码项目深挖**
  - 四层架构：core 纯协议(BaseNode/校验规则/表达式) → vue-app 加厚(FormComponent) → Builder(拖拽持久化) + Consumer(JSON→FormNode 递归渲染) → SimpleASTGenerator(.vue 字符串拼接)
  - 依赖倒置：core 不依赖 UI 框架，define 接口，上层各自实现

  **React 基础（与 Vue 对照）**
  - JSX 三条规则：根元素 / `{}` 写 JS 表达式 / 驼峰命名
  - React 无语法糖：v-model/v-for/v-if 全展开为原生 JS
  - 父/子通信：无 `$emit`，子调父=父把回调函数通过 props 传下去

  **Zustand 状态管理**
  - Zustand = React 版 Pinia，`set()` 手动触发渲染，`get()` 读最新值
  - Pinia vs Vuex vs zustand 三方对比表

  **React Router vs Vue Router 守卫**
  - Vue：全局 beforeEach 统一安检
  - React：每个路由包裹 `<AuthGuard>` 组件，`<Navigate to="/login" replace />`

  **Node.js 深入**
  - `app.use`(所有方法) vs `app.get/post`(特定方法)
  - 异常处理四参数：`(err, req, res, next)` ← 四个参数区分异常 vs 普通中间件

  **算法手写**
  - Promise.retry：递归 attempt(n)，n<=1 停
  - Promise 并发调度器：limit(上限)+running(当前)+index(下一个)
  - 虚拟滚动：startIndex/visibleCount/endIndex/offsetY/phantomHeight
  - 树与数组互转：arrToTree(Map+parentId) / treeToArr(队列/栈)

  **TS 工具类型**
  - Partial(全可选) / Pick(挑几个) / Omit(扔几个) / Record(key+value 批量造)

  **MCP 协议**
  - AI 与外部工具通信的标准 JSON-RPC 2.0 通道 → AI 世界的 USB 扩展坞
  - MCP != 中间件（是协议规范不是请求处理函数）
  - 已配置 sqlite MCP（直连 database.sqlite）+ playwright MCP
